# Project Software

Application Django avec une interface React pour Solidarité Ensemble.

## Lancer l'application

1. Installer les dépendances Python : `python -m pip install -r requirements.txt`
2. Construire l'interface : `cd frontend`, puis `npm install` et `npm run build`
3. Depuis la racine du projet, lancer Django : `python manage.py runserver`

Le serveur Django affiche l'interface compilée à l'adresse http://127.0.0.1:8000/.
